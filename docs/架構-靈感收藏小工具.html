靈感收藏小工具

在安卓手機上幾秒鐘存下截圖、連結、分類和關鍵字，照片放 Google 雲端硬碟；備課時打一兩個字就能找回來。這頁是開工前的規劃，還沒有寫任何程式。

只有自己用安卓主畫面每月 0 元・不綁卡狀態：待確認

你做的選擇

你選了什麼為什麼這樣選對你的好處代價
只有自己用收藏是給自己備課用不用登入帳號，打開就能存之後想跟夥伴共用，要另外改
裝在主畫面，能從 IG／FB 分享進來以前切換 LINE、找對話最麻煩存一筆不用再複製連結、切換 App剪貼簿貼圖和分享選單只能在你手機上實測確認
一筆只放一張照片多張就分成多筆清單裡每張小圖都對應一則，一眼認得同一個主題有好幾張，要存好幾次
不用 AI，關鍵字自己打口說錯字多、改起來麻煩不花 AI 費用，搜尋結果完全照你打的字關鍵字要自己想；照片裡的字搜不到
五個分類按鈕：烘焙、烹飪、手作、金句、好文你過去每則都先打分類點一下就好，不會打錯字不能臨時新增第六個分類（要改程式）
資料存 Google 雲端硬碟＋試算表你原本就想放雲端硬碟；另一個選項 Firebase 較快，但存照片要綁信用卡0 元、不綁卡，資料都在自己帳號，試算表也能當備份每次儲存要等 1～3 秒
網頁放 GitHub Pages你上一個工具就是這樣放的不用再學新的上線方式原始碼會公開（但通行碼和資料不在裡面）
照片設「知道連結的人可檢視」工具才能直接顯示小圖清單打開就有圖，不用一張張等拿到那串亂碼網址的人看得到照片
通行碼只輸入一次每次輸入太麻煩打開就用，外人仍然送不進資料清除瀏覽器資料或換手機要重新輸入
沒網路先存手機，有網路自動補傳，傳完才說「已存入」照片絕對不能不見，行動網路也要能傳不會誤以為存好就離開，資料不會掉訊號差時，「已存入」會晚一點才出現
點開一筆可以改分類和關鍵字，也能刪除打錯要能改；素材大約半年就用不到不用刪掉重存；搜尋結果保持在有用的內容多一個單筆畫面
舊資料不匯入舊素材大多用過了；金句、好文自己重存順便複習省下整理和匯入的時間手機舊截圖要你自己挑完才能刪
用一週都沒掉資料就算完成先定標準，避免一直加功能知道什麼時候可以放心離開 LINE要實際用滿一週才能下結論
灰藍色＋俐落極簡截圖本身顏色很多照片是畫面主角，好認畫面比較素，沒有裝飾

最高原則重點

名詞指的是不是指
一筆資料最多一張照片＋可有可無的連結＋一個分類＋關鍵字一則 LINE 訊息；多張照片
分類五個固定按鈕之一關鍵字
已存入雲端確認寫好之後才出現「按下儲存」
排隊中還在手機、等著送上雲端失敗或可丟棄
通行碼證明是你本人送的一組密語Google 帳號密碼

紅線規則

  1. 雲端確認寫入前，手機裡那一份絕對不刪。
  2. 「已存入」只在雲端確認後顯示。
  3. 同一筆重送不會變成兩筆。
  4. 行動網路也要上傳，不限 WiFi。
  5. 通行碼和雲端網址不放進公開的原始碼。
  6. 不加需求文件沒有的欄位或功能；要加先改需求。
  7. 刪除照片只丟進雲端硬碟垃圾桶。

上線標準：連續用一週，每天存的都「已存入」，試算表、雲端硬碟和工具清單的筆數一致。
