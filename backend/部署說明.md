# 部署說明：從電腦到手機

照順序做三段：①雲端小程式 ②網頁上線 ③手機安裝。全部都是免費的。

---

## ① 雲端小程式（Apps Script）

1. 用電腦開 https://script.new ，登入你的 Google 帳號，會開出一個新專案
2. 左上角「未命名的專案」改名為 **靈感收藏雲端**
3. 左邊已經有一個 `程式碼.gs`：把裡面全部刪掉，貼上 `backend/Code.gs` 的全部內容
4. 左邊「檔案」旁的 ＋ → **指令碼** → 取名 `logic` → 貼上 `backend/logic.js` 的全部內容
5. 按上方儲存（磁碟圖示）
6. 上方的函式下拉選單選 **setup** → 按 **執行**
   - 會跳出「需要授權」→ 選你的帳號
   - 出現「Google 尚未驗證這個應用程式」→ 點 **進階** → **前往「靈感收藏雲端」（不安全）** → **允許**
     （這是你自己寫的程式，所以 Google 沒有審核過，這個畫面是正常的）
7. 下方「執行紀錄」會出現三行，**把「通行碼」那串抄下來**
   - 你的雲端硬碟會多一個「靈感收藏」資料夾，裡面有「靈感收藏資料庫」試算表
8. 右上角 **部署** → **新增部署作業**
   - 齒輪圖示選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按 **部署**
9. **複製「網頁應用程式」網址**（`https://script.google.com/macros/s/…/exec`），跟通行碼放在一起

### 之後改了雲端程式要怎麼更新
**部署** → **管理部署作業** → 鉛筆圖示 → 版本選 **新版本** → **部署**。
這樣網址不會變，手機不用重新設定。
⚠️ 不要按「新增部署作業」，那會產生新網址，舊網址還是跑舊程式。

---

## ② 網頁上線（GitHub Pages）

1. 在 GitHub 建一個新的 repo，例如 `inspiration-box`（Public）
2. 把專案推上去（`node_modules` 已在 .gitignore 裡，不會被推上去）
3. repo 的 **Settings** → **Pages**
   - Source：**Deploy from a branch**
   - Branch：**main**、**/ (root)** → **Save**
   - 如果 Save 是灰的：先把 Branch 改成 None 按 Save，再改回 main 按 Save（你上次遇過）
4. 到 **Actions** 分頁，看到 *pages build and deployment* 變綠勾，再等一分鐘
5. 網址會是 `https://<你的帳號>.github.io/inspiration-box/`

### 之後改了網頁要怎麼更新
改完先跑 `npx vitest run` 全部通過 → 把 `sw.js` 第一行的 `VERSION` 加 1（例如 v1 → v2）→ 推上 GitHub。
手機關掉 App 再打開一兩次就會換成新版。

---

## ③ 手機安裝

1. 安卓手機用 **Chrome** 打開上面的 GitHub Pages 網址
2. 右上角 ⋮ → **安裝應用程式**（或「加到主畫面」→ 安裝）
3. 從主畫面打開「靈感收藏」，第一次會出現設定頁：貼上雲端小程式網址和通行碼 → 儲存設定

## 手機實測清單（電腦上測不到的部分）

- [ ] 存一筆：試算表多一列、雲端硬碟「靈感收藏」資料夾多一張照片（T05）
- [ ] 截圖後，長按新增畫面的虛線框 →「貼上」→ 截圖出現（T07）
- [ ] 或按「從剪貼簿貼上」→ 允許 → 截圖出現（T07）
- [ ] 以上兩種都不行時，「選照片」可以選到最新的截圖（T07）
- [ ] IG、FB、Threads 各按一次分享 → 選「靈感收藏」→ 連結自動帶入（T08）
- [ ] 相簿選一張照片 → 分享 →「靈感收藏」→ 照片帶入（T08）
- [ ] 搜尋頁的小圖看得到；點開一筆，大圖看得到（照片顯示方式）
- [ ] 開飛航模式存一筆 → 顯示「排隊中 1 筆」→ 關掉飛航 → 變成「已存入 😊」（T13）
- [ ] 飛航模式下從主畫面打開 App，新增畫面照常出現（T12）
- [ ] 連續用一週，每天的資料都「已存入」，試算表、雲端硬碟、工具清單筆數一致（T13）

任何一項不通過，把畫面截圖給我看。
